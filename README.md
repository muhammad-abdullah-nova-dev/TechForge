# ⚒️ TechForge

> **Build knowledge. One concept. Every day.**

The goal is simple:

**Learn → Understand → Document → Revise → Repeat.**

This repository collects important concepts into concise, interview-focused documentation so that learning doesn't remain scattered across videos, articles, courses, and random notes.

# 🧠 What Makes TechForge Different?

TechForge is built around **understanding instead of memorization**.

A good technical resource should not only tell you *what* something is.

It should help you understand:

* **Concept** — What exactly is it?
* **Purpose** — Why was it created?
* **Mechanism** — How does it work?
* **Usage** — Where is it useful?
* **Trade-offs** — What are its advantages and disadvantages?
* **Comparison** — How is it different from related concepts?
* **Interview Perspective** — How can you explain it clearly?
* **Follow-ups** — What deeper questions might come next?

# 🗂️ Knowledge Categories

TechForge will gradually cover topics such as:

### 🧩 Programming Fundamentals

Variables, data types, operators, control flow, functions, memory, pointers, recursion, error handling, and core programming concepts.

### 🧱 Object-Oriented Programming

Classes, objects, constructors, destructors, encapsulation, inheritance, abstraction, polymorphism, composition, aggregation, interfaces, and design principles.

### 🧠 Data Structures & Algorithms

Arrays, linked lists, stacks, queues, hash tables, trees, graphs, sorting, searching, recursion, dynamic programming, greedy algorithms, and complexity analysis.

### 🌐 Web Development

Internet fundamentals, browsers, HTTP/HTTPS, DNS, cookies, sessions, caching, security fundamentals, and how web applications communicate.

### 🎨 Frontend Development

HTML, CSS, JavaScript, DOM, events, asynchronous programming, browser APIs, responsive design, frameworks, and frontend architecture.

### ⚙️ Backend Development

Servers, databases, authentication, authorization, middleware, application architecture, caching, logging, scalability, and backend engineering.

### 🔌 APIs & Web Services

REST, endpoints, HTTP methods, status codes, headers, request/response cycles, authentication, authorization, API security, versioning, pagination, and API design.

### 🤖 Artificial Intelligence

AI fundamentals, machine learning foundations, model concepts, training, inference, evaluation, and modern AI workflows.

### 📊 Data Science

Data preparation, statistics, visualization, exploratory analysis, machine learning fundamentals, model evaluation, and data-driven problem solving.

# 🛠️ Principles

TechForge follows a few simple rules:

### 01 — Quality over quantity

A useful explanation is more valuable than a huge collection of shallow notes.

### 02 — Fundamentals first

Strong fundamentals make advanced technologies easier to understand.

### 03 — Learn by connections

Concepts should connect to other concepts rather than exist as isolated definitions.

### 04 — Interview ready

Important concepts should be explainable clearly in an interview.

### 05 — Consistency beats intensity

One useful contribution every day compounds into a huge knowledge base.

### 06 — Keep improving

Older documents can be updated when understanding improves or better explanations are discovered.
